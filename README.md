# Study Scheduler

Study Scheduler is a lightweight Python application for organizing study sessions, assignments and exam preparation.

## Features

- Subject management
- Study schedule
- Homework tracker
- Deadlines
- Statistics
- JSON storage
- Export support

## Requirements

- Python 3.11+

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

## Menu

```
1. Subjects
2. Schedule
3. Homework
4. Statistics
5. Export
6. Exit
```
